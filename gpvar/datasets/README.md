# Bundled data sets

| File | Content | Source |
|---|---|---|
| `fredqd_subset.csv` | 26 quarterly series from FRED-QD, vintage 2026-08 (1959Q1-2026Q2). Row 2 holds the FRED-QD transformation codes. | McCracken, M. W. and Ng, S. (2020), "FRED-QD: A Quarterly Database for Macroeconomic Research", *FRB St. Louis Working Paper* 2020-005. https://www.stlouisfed.org/research/economists/mccracken/fred-databases |
| `jln_macro_uncertainty.csv` | Monthly macroeconomic uncertainty index (h = 1, 3, 12), 1960:07-2026:06, August 2026 update. | Jurado, K., Ludvigson, S. C. and Ng, S. (2015), "Measuring Uncertainty", *American Economic Review* 105(3), 1177-1216. https://www.sydneyludvigson.com/macro-and-financial-uncertainty-indexes |

The data are redistributed for reproducibility of the examples only; please cite the original sources.
